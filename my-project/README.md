## What I Learned

### 1. Command-Line Navigation and File Management

I learned how to navigate directories and manage files using terminal commands instead of relying entirely on the graphical file explorer.

Some of the commands I practised include:

- `pwd` – Displays the current working directory.
- `cd` – Changes the current directory.
- `ls` – Lists files and directories.
- `mkdir` – Creates directories.
- `mkdir -p` – Creates nested directories.
- `touch` – Creates files.
- `cat` – Displays file contents.
- `cp` – Copies files.
- `mv` – Moves or renames files.
- `rm` – Removes files.

### 2. Useful Terminal Commands

I also learned how to search for files, inspect file contents, and review command history using commands such as `find`, `grep`, `head`, `tail`, `wc`, and `history`.

### 3. Git and GitHub

I learned how Git tracks changes in a project and how GitHub stores remote repositories.

I practised the basic Git workflow:

```bash
git status
git add .
git commit -m "Docs: update project documentation"
git push
```

I also learned about branches, merging, remote repositories, and the importance of meaningful commit messages.

### 4. Shell Scripting

I was introduced to Bash scripting and how scripts can automate repetitive tasks, such as creating a standard project structure.

### 5. Problem-Solving

I learned that using the terminal requires understanding the command being used, the current working directory, and the shell in which a command is executed. Debugging errors helped me become more careful when running commands and writing scripts.

## Challenges Faced

One of my main challenges was understanding which terminal commands to use and where to execute them.

I also encountered difficulties while working with shell scripts. This helped me understand the importance of using the correct syntax and ensuring that a script contains executable commands rather than copied instructions.
