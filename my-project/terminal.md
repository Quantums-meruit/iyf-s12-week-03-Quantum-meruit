## How i archived

1. Clone the repository.
2. Open the terminal `ctrl + j`.
3. Run Mkdir `my-project`, `mkdir src`, `mkdir docs`, and `mkdir tests` simultenously.
4. Navigate to `cd src`,
5. Create a nested folder `mkdir -p css`, `mkdir -p js ` and `mkdir images`.
6. Create a `README.md` by running `touch README.md`
