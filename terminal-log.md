# Terminal commands i've used

- `pwd` - print working directory path
- `cd` - changes directory
- `mkdir <folder-name` - make new directory folder
- `code <filename>` - code opens a text file
- `git  init` - initialises git
- `git merge` -  merges branches
- `git push` - pushes git changes to github
- `git branch` - checks which branch one is in
- `git switch` - switches branches
- `git checkout` - logs of current branch
